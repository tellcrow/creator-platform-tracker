创作平台长期数据记录器 v0.3.6
Windows 便携版使用说明

一、准备与启动

本版面向 Windows 10 64 位，已内置 Python 运行组件。
微信公众号采集使用本机的 Microsoft Edge 或 Google Chrome。
小红书和抖音采集需要本机安装 Google Chrome。

右键 ZIP，选择「全部解压缩」，解压到文档等有写入权限的文件夹。
打开解压后的 WeChatTracker_v0.3.6 文件夹，双击 WeChatTracker.exe。
请把 WeChatTracker.exe 和同级的 _internal 文件夹一起保留。

二、登录与第一次采集

1. 在窗口左上角选择「微信公众号」「小红书」或「抖音」，将
   「我的公众号」或「我的账号」替换为所选平台后台显示的实际账号名称。
2. 点「① 扫码登录」，在软件打开的专用浏览器中完成平台登录。
3. 登录完成后回到软件，点「② 采集当前」。
4. 打开「运行记录」，查看进度、采集结果和异常。采集的数据可在「文章总表」
   查看，双击一条记录可以查看历史曲线与明细。

每个平台都需要单独设置账号名称并登录。配置好多个平台后，可用
「一键全部采集」同时采集。需要中断时点「停止全部」。
采集期间请让专用浏览器保持当前账号和页面。登录失效时，重新点
「① 扫码登录」。如提示账号不符，请核对软件里填写的后台显示名称，
并确认专用浏览器登录的是同一个账号。

三、定时与重点文章

首次启动时，定时采集默认关闭。需要全量定时时，在左上角切换到对应平台，
打开「定时采集与备份」，选「按间隔」或「每日固定时间」，再点
「保存定时设置（绑定当前平台和账号）」。每个平台分别设置，时间以本机为准。
需要只跟踪 1–5 篇作品时，在「文章采集」选中作品，点「加入观察」，
设置间隔后点「保存并开始」。点「暂停」即可停用这组计划。
定时运行期间请保持软件打开、电脑唤醒。软件可最小化。

四、导出、换电脑与分享

- 导出表格。在「文章总表」点「导出 Excel」，保存当前平台和账号的表格。
- 备份历史。在「定时采集与备份」点「导出 JSON」或「导出 gzip」，
  保存 .json 或 .json.gz 备份文件。
- 换电脑。在新电脑解压 ZIP 并启动软件，用顶部「导入备份」选择自己的备份。
  历史记录会合并去重。之后重新登录，并按需要重新启用定时采集。
- 分享软件。直接分享这份原始 ZIP。备份文件含账号名称和采集历史，请自行保管。

程序首次运行会在 exe 同级创建 data 文件夹。tracker.sqlite 保存账号设置和
采集历史，run.log 保存运行记录，browser_profiles 保存采集浏览器的登录状态。

五、从源码运行（可选）

在项目目录打开 PowerShell，使用 Python 3.12 新建虚拟环境并安装依赖。

  py -3.12 -m venv .venv
  .\.venv\Scripts\python.exe -m pip install -r requirements.txt
  .\.venv\Scripts\python.exe main.py

如需构建便携程序，激活同一个 Python 3.12 虚拟环境，安装
requirements-build.txt 中的依赖，再运行 build.ps1。

  .\.venv\Scripts\Activate.ps1
  python -m pip install -r requirements-build.txt
  .\build.ps1

构建结果在终端最后显示的 dist-* 目录中。
